# Hospital Management System (SQL)

## Project Overview
This project demonstrates a Hospital Management System database built using MySQL. It stores and manages patient, doctor, appointment, and billing information.

## Database Tables
- Patients
- Doctors
- Appointments
- Billing

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT
- SUM
- AVG
- MAX
- MIN
- INNER JOIN
- Subqueries
- VIEW
- UPDATE
- DELETE

## Tools Used
- MySQL Workbench
- GitHub

## Project Features
- Patient Management
- Doctor Management
- Appointment Tracking
- Billing Management
- Data Analysis using SQL Queries
