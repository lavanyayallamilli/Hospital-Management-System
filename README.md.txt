# Hospital Management System (SQL)

## Project Overview
This project demonstrates a Hospital Management System database built using MySQL. It manages patients, doctors, appointments, and billing information.

## Database Tables
- Patients
- Doctors
- Appointments
- Billing

- CREATE DATABASE
- CREATE TABLE

- AVG

- MIN
- INNER JOIN
- Subqueries
- VIEW

- DELETE
